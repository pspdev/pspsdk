◆ sceUsbAccGetAuthStat()

int sceUsbAccGetAuthStat ( void )

Gets the authentication state of the connected USB accessory.

Returns PSP_USBACC_ERROR_NOT_AUTHENTICATED while the accessory has not been authenticated yet or the authentication failed, and PSP_USB_ERROR_BUS_DRIVER_NOT_STARTED when no accessory is attached.

Available on firmware 2.70 and higher only.

Returns
0 on success, < 0 on error

◆ sceUsbAccGetInfo()

int sceUsbAccGetInfo ( SceUsbAccInfo * info)

Gets the information block sent by the connected USB accessory.

Returns PSP_USBACC_ERROR_NOT_AUTHENTICATED while the accessory has not been authenticated yet or the authentication failed, PSP_USB_ERROR_BUS_DRIVER_NOT_STARTED when no accessory is attached, and PSP_USB_ERROR_INVALID_ARGUMENT if info is NULL or not a user pointer.

Available on firmware 2.70 and higher only.

Parameters
info- pointer to a structure that receives the information
Returns
0 on success, < 0 on error
