◆ sceUsbAccIntrInReq()

int sceUsbAccIntrInReq ( struct UsbdDeviceReq * req)

Queues a packet to be sent from the PSP to the accessory on the interrupt endpoint (EP 0x81).

req->data must point to a SceUsbAccPacket.

Available on firmware 2.70 and higher only.

Parameters
req- UsbdDeviceReq whose data points to a filled SceUsbAccPacket
Returns
0 on success, PSP_USB_ERROR_BUS_DRIVER_NOT_STARTED if no accessory is attached, PSP_USB_ERROR_INVALID_ARGUMENT if the payload is too long

◆ sceUsbAccRegisterType()

int sceUsbAccRegisterType ( u16 type)

Registers the accessory type(s) the caller handles (PspUsbAccType bits).

An accessory is accepted only if it advertises every registered type (none registered = any accessory accepted).

Available on firmware 2.70 and higher only.

Parameters
type- mask of accessory type bits to register
Returns
0 on success, PSP_USB_ERROR_ALREADY_DONE if any requested bit is already registered

◆ sceUsbAccUnregisterType()

int sceUsbAccUnregisterType ( u16 type)

Unregisters accessory type(s) previously registered with sceUsbAccRegisterType.

Available on firmware 2.70 and higher only.

Parameters
type- mask of accessory type bits to unregister
Returns
0 on success, PSP_USB_ERROR_DRIVER_NOT_FOUND if none of the requested bits was registered
