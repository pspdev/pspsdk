◆ PspUsbGpsPowerSaveMode

enum PspUsbGpsPowerSaveMode

Power-save modes for sceUsbGpsSetPowerSaveMode.

Each selects how much the receiver sleeps between fixes while the PSP is active vs. idle. Sleeping more saves power but reduces the fix frequency.

Enumerator
PSP_USBGPS_POWER_SAVE_MODE_OFF 

No power saving.

The receiver tracks continuously at full power.

PSP_USBGPS_POWER_SAVE_MODE_IDLE_LIGHT 

Full power when active, sleeps a little between fixes when idle.

PSP_USBGPS_POWER_SAVE_MODE_IDLE_DEEP 

Full power when active, sleeps a lot between fixes when idle.

PSP_USBGPS_POWER_SAVE_MODE_MAX 

Sleeps a little when active, sleeps a lot when idle.

PSP_USBGPS_POWER_SAVE_MODE_ACTIVE_LIGHT 

Sleeps a little when active, full power when idle.

◆ PspUsbGpsResetType

enum PspUsbGpsResetType

Receiver reset levels for sceUsbGpsReset, ordered from most to least data discarded.

Each performs a full receiver restart. They differ only in what acquired data is kept.

Enumerator
PSP_USBGPS_RESET_COLD 

Cold start: discard the ephemeris, almanac, last position and time held in memory.

Slowest to get the next fix.

PSP_USBGPS_RESET_WARM 

Warm start: discard ephemeris only, keeping almanac, last position and time.

PSP_USBGPS_RESET_HOT 

Hot start: restart from the position and time retained in the receiver.

PSP_USBGPS_RESET_HOT_SEEDED 

Hot start: restart from the last known position and the current time supplied by the PSP.

◆ sceUsbGpsResetInitialPosition()

int sceUsbGpsResetInitialPosition ( float latitude,
float longitude,
float altitude,
float geoidsep )

Seeds the GPS receiver with a known starting position to shorten the time to first fix.

Takes effect while the receiver is still searching. It is a no-op once the receiver already has a fix. The receiver is restarted with the new position automatically.

The latitude, longitude and altitude can be taken straight from a prior sceUsbGpsGetData result. altitude + geoidsep is the WGS84 ellipsoidal height. Pass geoidsep as 0 when it is unknown (the resulting error is negligible for a seed).

Available on firmware 3.30 and higher only.

Parameters
latitude- latitude in degrees, -90 to 90 (south negative)
longitude- longitude in degrees, -180 to 180 (west negative)
altitude- height above mean sea level in meters, -10000 to 10000
geoidsep- geoid-to-ellipsoid separation in meters, -1000 to 1000
Returns
0 on success, < 0 on error

◆ sceUsbGpsSaveInitData()

int sceUsbGpsSaveInitData ( void )

Saves the GPS init (assistance) data to the file selected with sceUsbGpsSetInitDataLocation.

The data (last known position, time and ephemeris/almanac) is produced by the receiver while it runs. This call only writes the current in-memory copy to storage so the next session can obtain a fix faster.

Available on firmware 2.70 and higher only.

Returns
0 on success, < 0 on error. Returns PSP_USBGPS_ERROR_NO_INIT_DATA if the receiver has not produced any assistance data yet.

◆ sceUsbGpsSetPowerSaveMode()

int sceUsbGpsSetPowerSaveMode ( u32 mode,
u32 interval )

Sets the GPS receiver power-save mode.

Power saving engages once the PSP has been idle (no user input) for the given interval, after which the receiver duty-cycles as described by PspUsbGpsPowerSaveMode. Should be called immediately after sceUsbGpsOpen. It fails once the receiver has started running.

Available on firmware 3.00 and higher only.

Parameters
mode- one of PspUsbGpsPowerSaveMode
interval- idle time in seconds before power saving engages, 30 to 600
Returns
0 on success, < 0 on error

◆ sceUsbGpsSetStaticNavMode()

int sceUsbGpsSetStaticNavMode ( u8 mode)

Sets the static navigation mode.

When enabled, the receiver filters out small movements at low speed to keep the reported position stable. Can be called any time after sceUsbGpsOpen. Takes effect immediately if the receiver is running, otherwise when it starts.

Available on firmware 3.70 and higher only.

Parameters
mode- one of PspUsbGpsStaticNavMode
Returns
0 on success, < 0 on error
